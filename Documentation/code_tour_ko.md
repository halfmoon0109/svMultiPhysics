# svMultiPhysics 코드 투어 (초보자용)

이 문서는 **개발 지식이 전무한 사람도 이해할 수 있도록** svMultiPhysics 코드의 구조와 실행 흐름을 설명합니다.

## 1) 이 프로그램은 무엇을 하는가?

svMultiPhysics는 **유체(혈액)와 고체(혈관 벽)의 상호작용**을 계산하는 다중 물리 시뮬레이션 프로그램입니다. 혈액의 흐름이 혈관을 변형시키고, 그 변형된 형태가 다시 혈류에 영향을 주는 현상을 계산합니다.

## 2) 큰 그림: 폴더 구조를 “조립 설명서”로 이해하기

### ✅ 최상위 조립 설명서: `CMakeLists.txt`

프로그램을 어떻게 빌드(조립)하는지 정의한 설계도입니다. 외부 라이브러리(Externals)와 본체 코드(Code)를 각각 빌드하도록 구성되어 있습니다.

### ✅ 실제 계산 엔진: `Code/`

실제 물리 계산 로직이 들어 있는 “엔진실”입니다. 그중 핵심은 `Code/Source/solver` 폴더입니다.

### ✅ 사용 설명서: `README.md`

빌드, 실행, 테스트 방법이 정리된 사용자 안내서입니다.

### ✅ 내부 설계 설명서: `Documentation/internal.md`

코드가 왜 절차형 구조인지, 네임스페이스/클래스가 어떤 방식으로 사용되는지 설명합니다.

### ✅ 테스트: `tests/`

테스트 시나리오와 데이터가 모여 있는 폴더입니다. `tests/README.md`에 실행 방법이 정리되어 있습니다.

## 3) 초보자가 알아야 할 설계 특징

### ✅ 절차형 구조

svMultiPhysics는 객체지향보다 **함수들이 순차적으로 실행되는 절차형 구조**를 유지합니다. 즉, “A → B → C 순서”로 흐름을 이해하는 것이 중요합니다.

### ✅ 파일명과 네임스페이스가 1:1

각 파일은 동일한 이름의 네임스페이스를 가지며, 파일 단위로 기능이 묶입니다.

### ✅ 클래스는 데이터 상자 역할

클래스는 복잡한 상속 구조보다는 **데이터를 담는 상자** 역할을 합니다.

## 4) 실제 실행 흐름 투어

아래는 프로그램이 실행될 때 내부에서 어떤 단계가 진행되는지를 **초보자용 흐름**으로 정리한 것입니다.

### 🟢 Step 1: 입력 파일 읽기

사용자가 제공한 XML 입력 파일을 읽어 solver 설정을 저장합니다.

* 핵심 클래스: `Parameters`
* 전체 흐름 제어: `Simulation`

### 🟢 Step 2: 메시(격자) 읽기

VTU/VTP 파일에서 공간 격자 데이터를 읽습니다. 요소 타입/형상 함수/적분점 등의 계산 준비가 여기서 이루어집니다.

### 🟢 Step 3: 방정식/경계조건 설정

어떤 물리 방정식을 풀지, 경계 조건은 무엇인지 설정합니다.

### 🟢 Step 4: 병렬 분배

계산을 여러 프로세서에 나누기 위해 격자와 방정식을 분할합니다.

### 🟢 Step 5: 초기화

행렬 구조, 물성값, 경계조건 초기값 등을 준비합니다.

### 🟢 Step 6: 반복 계산

시간 스텝마다 **예측 → 조립 → 경계조건 적용 → 선형 시스템 풀이** 과정을 반복합니다.

## 5) 초보자가 다음에 보면 좋은 문서

1. `Code/Source/solver/README.md` - 상세 흐름도와 함수 호출 순서가 정리된 핵심 문서
2. `README.md` - 빌드/실행 절차를 직접 따라 하며 감을 잡기
3. `tests/README.md` - 테스트 구조와 실행 방법
